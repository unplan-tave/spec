# Feature Specification: 카드 등록 · 편집 · 상세 · 큐→핀 전환

**Feature Branch**: `004-card`

**Created**: 2026-11-24

**Status**: Draft

**Input**: 원본 기능명세서 R144~R168, R170~R260, IA R30~R45, 초기 기능명세서 pin card·add card 영역

**관련 화면**: `ADD-SHEET`, `EDIT-CARD`, `EDIT-TAG`, `EDIT-DATETIME`, `EDIT-TIME-UNSET`, `EDIT-LOCATION`, `EDIT-DEADLINE`, `CARD-DETAIL-PIN`, `CARD-DETAIL-QUEUE`, `CARD-REC-TIME`, `CARD-CONVERT`, `CARD-CONVERT-MANUAL`

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 핀 카드 등록 (Priority: P1)

**Acceptance Scenarios**:

1. **Given** `ADD-SHEET`, **When** "일정 카드 등록하기"를 누르면, **Then** `EDIT-CARD`가 열리고 카드 종류 = 핀 카드, 컨디션 태그 = 일상 작업, 나머지는 빈 상태다.
2. **Given** `EDIT-CARD`, **When** 제목을 입력하면, **Then** 제목에 맞는 컨디션 태그로 자동 변경된다.
3. **Given** 제목·컨디션 태그·날짜·시작/종료 시각이 모두 유효, **When** 완료를 누르면, **Then** 카드가 저장되고 `CARD-DETAIL-PIN`으로 이동한다.
4. **Given** 필수값이 빠진 상태, **When** 완료를 누르면, **Then** "아직 입력되지 않은 필수 정보가 있어요!" 토스트와 함께 빠진 항목이 빨간색으로 표시되고 저장되지 않는다.
5. **Given** 같은 날 08:00~09:00 일정이 있을 때, **When** 09:00~10:00으로 시간을 정하면, **Then** "다른 일정과 시간이 겹쳐요!" 토스트가 뜨고 등록할 수 없다.

> ⚠️ 4번은 R182(필수값 누락 시 완료 버튼 **비활성**)와 R255(누락 상태에서 완료 **선택 시** 토스트)가 동시에 성립할 수 없다. [NEEDS CLARIFICATION: Q-067]

---

### User Story 2 - 큐 카드 등록 (Priority: P1)

**Acceptance Scenarios**:

1. **Given** `EDIT-CARD`, **When** 큐 카드 탭을 누르면, **Then** 날짜·시각 대신 마감일·소요 시간 항목이 표시된다.
2. **Given** `EDIT-DEADLINE`, **When** 1분/5분/10분/30분/1시간/3시간 버튼을 누르면, **Then** 소요 시간에 누적된다. 새로고침 버튼은 0시간 0분으로 되돌린다.
3. **Given** `EDIT-DEADLINE`, **When** "모르겠어요"를 누르면, **Then** "시간 미정"이 표시되고 "시간대 추천이 어려울 수 있어요!" 토스트가 뜬다. 시간 미정은 유효한 값이다.
4. **Given** 마감일이 설정됨, **When** `EDIT-CARD`를 보면, **Then** `YYYY.MM.DD`와 D-day가 표시된다 (마감 당일 D-0).

---

### User Story 3 - 날짜만 정하고 시각을 비운 경우 (Priority: P2)

**Acceptance Scenarios**:

1. **Given** `EDIT-DATETIME`에서 날짜만 선택, **When** 완료를 누르면, **Then** "시간이 정해지지 않은 일정인가요? 큐카드로 등록하면 빈 시간에 맞춰 일정을 추천해 드려요" 모달과 [큐카드로 바꾸기] [시간 입력하기] [이대로 저장하기]가 표시된다.
2. **When** 큐카드로 바꾸기 → **Then** 모달·바텀시트가 닫히고 카드 종류가 큐 카드가 된다.
3. **When** 시간 입력하기 → **Then** 바텀시트로 돌아가 시작 시각 휠 피커가 열린다.
4. **When** 이대로 저장하기 → **Then** 날짜만 설정된 상태로 `EDIT-CARD`로 돌아간다. [NEEDS CLARIFICATION: Q-006 시각 없는 핀 카드 허용 여부]

---

### User Story 4 - 카드 상세와 진행도 변경 (Priority: P1)

**Acceptance Scenarios**:

1. **Given** `CARD-DETAIL-PIN`, **When** 화면을 보면, **Then** 제목, 컨디션 태그, 진행도 바, 날짜, 시간이 보이고, 개인 태그·위치·메모는 값이 있을 때만 보인다.
2. **Given** 진행도 바, **When** 다른 단계를 누르면, **Then** 진행도가 바로 저장된다.
3. **Given** 상세 화면, **When** 편집을 누르면, **Then** 저장된 값이 채워진 `EDIT-CARD`가 열린다.

---

### User Story 5 - 큐 카드를 핀 카드로 전환 (Priority: P2)

**Acceptance Scenarios**:

1. **Given** `CARD-DETAIL-QUEUE`, **When** "추천 시간 확인하기"를 누르면, **Then** 배경이 어두워지고 `CARD-REC-TIME`에 추천 시간 선택지가 표시된다.
2. **Given** 추천 시간 하나를 선택, **When** "핀카드로 전환하기" → "추천 시간 기반 전환"을 누르면, **Then** 선택한 시간대가 핀 카드의 날짜·시작·종료 시각이 되고, 제목·태그·위치·메모는 유지되며, `CARD-DETAIL-PIN`으로 이동한다.
3. **Given** 추천 시간 데이터가 없음, **When** `CARD-REC-TIME`을 열면, **Then** "추천 시간 없음" 안내가 표시된다.

---

### User Story 6 - 일정 추가 바텀시트에서 추천 큐 카드 바로 넣기 (Priority: P2)

**Acceptance Scenarios**:

1. **Given** 추천 대상 큐 카드가 있음, **When** `ADD-SHEET`를 열면, **Then** "오늘 추가하기 좋은 일정"에 추천 이유, 제목, 추천 시작·종료 시각, 컨디션 태그, 개인 태그가 표시된다.
2. **When** 추천 큐 카드의 "일정 추가"를 누르면, **Then** 추천 시각으로 핀 카드가 등록된다.
3. **When** 추천 큐 카드의 "추천 삭제"를 누르면, **Then** 목록에서 빠지고 그날은 다시 추천되지 않는다.
4. **When** "전체 큐 카드 보기"를 누르면, **Then** 카드 유형 필터 = 큐 카드가 적용된 `CARD-LIST`로 이동한다.

---

### Edge Cases

- 단일 날짜에 시작 시각 > 종료 시각 → "다음날 종료되는 일정으로 등록할까요?" 토스트 [완료]. 완료를 누르면 종료일이 다음 날로 바뀐다. (R216, R217)
- 시작 시각 = 종료 시각: [NEEDS CLARIFICATION: Q-023]
- 메모 2,000자 초과 입력·붙여넣기 → 2,000자까지만 들어가고 "2000자까지만 입력 가능해요!" 토스트. (R234, R235)
- 개인 태그 100개 상태에서 생성 시도, 1~25자 범위 밖 → 생성 제한 + 안내. (R199)
- 상세 화면에서 이전 화면을 알 수 없을 때 뒤로 가기 → `CARD-LIST`. (R146)
- 추천 시간 기반 전환 시 추천 시간대가 이미 다른 일정과 겹치게 되었으면: [NEEDS CLARIFICATION: Q-022]

## Requirements *(mandatory)*

### Functional Requirements

**일정 추가 바텀시트** (`ADD-SHEET`)

- **FR-CARD-001**: "오늘 추가하기 좋은 일정" 영역과 "새로 만들기" 영역을 표시해야 한다. (R170, R171)
- **FR-CARD-002**: 당일 추천 대상 큐 카드 목록을 표시하고, 각 카드에 추천 이유·제목·추천 시작/종료 시각·컨디션 태그·개인 태그를 보여야 한다. 대상이 없으면 영역을 표시하지 않는다. (R172, R173) 추천 기준은 007.
- **FR-CARD-003**: 추천 삭제 시 그 큐 카드를 당일 추천에서 제외해야 한다. (R174) [NEEDS CLARIFICATION: Q-045 하루의 경계]
- **FR-CARD-004**: 일정 추가 시 추천 시각으로 핀 카드를 등록해야 한다. 등록할 수 없는 시간 조건이면 등록하지 않고 안내한다. (R175) [NEEDS CLARIFICATION: Q-027 원래 큐 카드는 전환인가 유지인가 / Q-068 등록 후 이동 화면]
- **FR-CARD-005**: "전체 큐 카드 보기"는 큐 카드 필터가 적용된 카드리스트로 이동한다. (R176)
- **FR-CARD-006**: "일정 카드 등록하기"는 `EDIT-CARD`를 신규 기본값으로 연다. (R177, R178)

**카드 편집 공통** (`EDIT-CARD`)

- **FR-CARD-010**: 헤더에 취소·완료, 본문에 카드 종류 탭, 제목, 컨디션 태그, 개인 태그, (핀) 날짜·시각 / (큐) 마감일·소요 시간, 위치, 메모를 표시해야 한다. (R179, R239, R240)
- **FR-CARD-011**: 신규 기본값: 카드 종류 = 핀 카드, 컨디션 태그 = 일상 작업, 나머지 빈 값. (R180)
- **FR-CARD-012**: 필수값 — 핀: 제목, 컨디션 태그, 시작일·종료일, 시작·종료 시각 / 큐: 제목, 컨디션 태그, 마감일, 소요 시간(미정 허용). 선택값: 개인 태그, 위치, 상세 위치, 메모. (R239, R240, R255)
- **FR-CARD-013**: 필수값 누락 처리 [NEEDS CLARIFICATION: Q-067 완료 버튼 비활성(R182) vs 누르면 토스트+빨간 표시(R255~R260)]
  - 누락 안내 방식을 택하면: 빠진 항목만 빨간색, 유효한 값이 들어오면 해당 항목 빨간색 해제. (R259, R260)
- **FR-CARD-014**: 완료 시 필수값·날짜·시간 유효성·일정 중복을 검증한 뒤 저장하고 상세 화면으로 이동해야 한다. 저장 실패 시 저장하지 않고 오류 안내. (R144, R183)
- **FR-CARD-015**: 취소 시 신규 카드를 저장하지 않고 이전 화면으로 돌아가야 한다. [NEEDS CLARIFICATION: Q-003 복귀 대상 (원본은 항상 `ADD-SHEET`)] (R181)
- **FR-CARD-016**: 기존 카드 수정 모드의 동작: [NEEDS CLARIFICATION: Q-028]
- **FR-CARD-017**: 카드 종류 탭으로 핀/큐를 바꾸면 해당 종류의 입력 항목을 표시해야 한다. 바꾸기 전에 입력한 날짜·시각 / 마감일·소요 시간을 유지하는가: [NEEDS CLARIFICATION: Q-069] (R238)

**제목·컨디션 태그·개인 태그** (`EDIT-TAG`)

- **FR-CARD-020**: 제목은 필수이며, 입력·수정 시 자동 분류로 컨디션 태그를 바꿔야 한다. (R184, R185) [NEEDS CLARIFICATION: Q-021 사용자 선택 우선 여부 / Q-054 최대 길이 / 분류 로직은 007]
- **FR-CARD-021**: 컨디션 태그 영역을 누르면 컨디션 태그 탭이, 개인 태그 영역을 누르면 개인 태그 탭이 선택된 태그 바텀시트가 열려야 한다. (R186~R188)
- **FR-CARD-022**: 컨디션 태그는 6개 중 하나만 선택한다. 새로 고르면 기존 선택을 대체한다. (R191)
- **FR-CARD-023**: 컨디션 태그 탭의 완료 버튼은 태그가 선택되었을 때만 활성, 개인 태그 탭은 항상 활성. (R190)
- **FR-CARD-024**: "컨디션 태그란?" 버튼은 태그별 설명 화면으로 전환하고, 돌아가기로 목록에 복귀한다. (R193, R194)
- **FR-CARD-025**: 개인 태그 탭은 검색바, 생성 버튼, 저장된 태그 목록(가나다순, 25자까지 말줄임 없이 표시)을 보여야 한다. (R196, R200)
- **FR-CARD-026**: 검색어와 일치하는 태그가 없으면 생성 버튼을 활성화하고, 있으면 비활성화한다. (R197, R198) 일치 기준(포함/완전 일치): [NEEDS CLARIFICATION: Q-070]
- **FR-CARD-027**: 개인 태그 생성: 1~25자, 계정당 최대 100개. 위반 시 생성 제한 + 안내. (R199)
- **FR-CARD-028**: 개인 태그는 여러 개 선택·해제할 수 있다. (R201)
- **FR-CARD-029**: 개인 태그 수정·삭제: [NEEDS CLARIFICATION: Q-031]
- **FR-CARD-030**: 컨디션 태그 탭과 개인 태그 탭에서 각각 바꾼 내용의 완료/취소 범위(탭별인가, 바텀시트 전체인가): [NEEDS CLARIFICATION: Q-071]

**날짜/시간** (`EDIT-DATETIME`, 핀 카드)

- **FR-CARD-040**: 날짜 영역 또는 시간 영역을 누르면 같은 날짜/시간 바텀시트(달력 + 시작 시각 + 종료 시각)를 연다. (R202~R204)
- **FR-CARD-041**: 달력에서 오늘은 흰색 점, 선택한 날짜는 파란색 원으로 표시한다. (R205)
- **FR-CARD-042**: 첫 탭은 시작일, 다른 날짜를 누르면 종료일로 기간을 설정하고, 선택된 날짜를 다시 누르면 해제한다. (R206~R208) [NEEDS CLARIFICATION: Q-024 세 번째 탭, 종료일이 시작일보다 앞일 때]
- **FR-CARD-043**: 시작·종료 시각은 00:00~23:59에서 휠 피커로 고른다. 분 단위 간격: [NEEDS CLARIFICATION: Q-072] (R209, R210)
- **FR-CARD-044**: 단일 날짜에서 시작 > 종료이면 다음 날 종료 확인 토스트를 띄우고, 완료 시 종료일을 다음 날로 바꾼다. (R216, R217)
- **FR-CARD-045**: 날짜와 시각이 모두 입력되면 다른 핀 카드와 겹치는지 확인해야 한다. 끝 시각 = 다른 일정 시작 시각도 겹침이다. 겹치면 "다른 일정과 시간이 겹쳐요!" 토스트를 띄우고 등록을 막는다. (R218~R221) [NEEDS CLARIFICATION: Q-022]
  - 수정 중인 자기 자신은 비교에서 제외한다. (제안)
- **FR-CARD-046**: 날짜만 선택하고 완료하면 시간 미설정 확인 모달(`EDIT-TIME-UNSET`)을 띄운다. 각 선택지 동작은 User Story 3. (R212~R215)
- **FR-CARD-047**: 취소 시 바텀시트에서 바꾼 내용은 버린다. (R211, POL-003)

**마감일/소요 시간** (`EDIT-DEADLINE`, 큐 카드)

- **FR-CARD-050**: 큐 카드의 마감일 또는 소요 시간 영역을 누르면 바텀시트(달력 + 소요 시간)를 연다. 소요 시간 초기값 0시간 0분. (R241, R242)
- **FR-CARD-051**: 마감일은 날짜 1개다. (R243) [NEEDS CLARIFICATION: Q-046 과거 날짜]
- **FR-CARD-052**: 소요 시간은 1분·5분·10분·30분·1시간·3시간 버튼으로 누적하고, 새로고침 버튼으로 0시간 0분 + 미정 해제. (R246, R247) [NEEDS CLARIFICATION: Q-047 최대값, 0분 유효성]
- **FR-CARD-053**: "모르겠어요"는 소요 시간을 미정으로 하고 안내 토스트를 띄운다. (R248~R251)
- **FR-CARD-054**: `EDIT-CARD`에 마감일 `YYYY.MM.DD`와 D-day(당일 D-0), 소요 시간 또는 "시간 미정"을 표시한다. (R244, R245, R254)

**위치·메모**

- **FR-CARD-060**: 위치 바텀시트: 취소·완료, 검색바, 최근 검색어(최신순, 개별 X 삭제, 전체 삭제, 없으면 "최근 검색 내역이 없습니다"). (R222~R228)
