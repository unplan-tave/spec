## User Scenarios & Testing *(mandatory)*

### User Story 1 - 컨디션에 맞는 일정 추천 받기 (Priority: P1)

**Acceptance Scenarios**:

1. **Given** 빈 시간과 맞는 큐 카드가 있음, **When** "컨디션 기반 추천 일정"을 누르면, **Then** 추천 이유와 추천 큐 카드 최대 3개가 바텀시트에 보이고 좌우로 넘겨 볼 수 있다.
2. **Given** 추천 화면, **When** 추천 수락을 누르면, **Then** 핀 카드가 만들어지고 바텀시트가 닫혀 `COND-MAIN`으로 돌아간다.
3. **Given** "기존 큐 카드 유지하기" 체크, **When** 수락하면, **Then** 큐 카드는 남고 핀 카드가 **추가**된다. 체크 해제면 큐 카드가 핀 카드로 **전환**된다.
4. **Given** 추천 화면, **When** "시간 직접 입력"으로 시각을 바꾸면, **Then** 바꾼 시각으로 수락된다. 종료가 시작보다 늦어야 한다.

---

### User Story 2 - 추천 실패 사유 알기 (Priority: P2)

**Acceptance Scenarios**:

1. **Given** 빈 시간이 없음, **When** 추천을 요청하면, **Then** "추천 일정을 찾지 못했어요! 여유 시간이 생기면 추천해 드릴게요"
2. **Given** 빈 시간은 있으나 맞는 큐 카드가 없음, **When** 추천을 요청하면, **Then** "추천 일정을 찾지 못했어요! 여유 시간에 딱 맞는 큐 카드가 없어요"

---

### User Story 3 - 기력 회복이 필요할 때 (Priority: P2)

**Acceptance Scenarios**:

1. **Given** 현재 컨디션이 기력 회복 상태, **When** 추천을 받으면, **Then** 기력 회복 태그 큐 카드가 먼저, 그다음 후보로 사용자의 컨디션 회복 방법이 버튼으로 보인다.
2. **Given** 회복 방법 후보가 보임, **When** 아무것도 고르지 않으면, **Then** 수락 버튼이 비활성이다. 하나를 고르면 활성.
3. **Given** 기력 회복 태그 큐 카드가 없음, **When** 추천을 받으면, **Then** 회복 방법 후보가 바로 보인다.

---

### Edge Cases

- 소요 시간이 미정인 큐 카드는 추천 대상인가: [NEEDS CLARIFICATION: Q-081] ("시간대 추천이 어려울 수 있어요!" 안내만 존재)
- 추천 시각이 그 사이 다른 일정과 겹치게 된 경우: [NEEDS CLARIFICATION: Q-022]
- 회복 방법을 고르고 수락하면 만들어지는 핀 카드의 제목·태그·시간: [NEEDS CLARIFICATION: Q-082]

## Requirements *(mandatory)*

### Functional Requirements

**컨디션 기반 추천** (`COND-REC`)

- **FR-REC-001**: 현재 컨디션·일정·큐 카드를 근거로 추천을 생성하고 성공/실패 화면을 표시한다. (R272)
- **FR-REC-002**: 성공 화면: 추천 이유, 추천 큐 카드 최대 3개(좌우 탐색), "기존 큐 카드 유지하기" 체크박스, "시간 직접 입력", "추천 수락". (R273, R274)
  - 체크박스 기본값: [NEEDS CLARIFICATION: Q-083]
- **FR-REC-003**: 시간 직접 입력: 시작·종료 시각을 바꿀 수 있고 종료 > 시작이어야 한다. (R276, R277)
- **FR-REC-004**: 수락 시 체크 → 큐 카드 유지 + 핀 카드 추가 / 해제 → 큐 카드를 핀 카드로 전환. 실패 시 기존 상태 유지 + 안내. (R275, R278, R279) [NEEDS CLARIFICATION: Q-027]
- **FR-REC-005**: 실패 사유 판별: 빈 시간이 없으면 "빈 시간 부족", 빈 시간은 있으나 맞는 큐 카드가 없으면 "큐 카드 매칭 실패". 각각 User Story 2의 문구. (R280, R281)
- **FR-REC-006**: 기력 회복 상태에서는 기력 회복 태그 큐 카드를 먼저, 그다음 사용자가 설정한 회복 방법을 하나의 후보로 제시한다. (R282~R284)
- **FR-REC-007**: 회복 방법은 한 번에 하나만 선택하며, 기력 회복 상태에서만 선택이 수락의 필수 조건이다. (R285, R286)
- **FR-REC-008**: 회복 방법은 사용자가 설정한 순서대로 표시한다. [NEEDS CLARIFICATION: Q-013 순서 규칙]
