# Feature Specification: 설정 (계정 · 알림 · 추천 개인화 · 이용 안내)

**Feature Branch**: `009-settings`

**Created**: 2026-11-24

**Status**: Draft

**Input**: 원본 기능명세서 R335~R373 (R335~R366은 IA 나열만 있음), IA R56~R87

**관련 화면**: `SET-MAIN`, `SET-ACCOUNT`, `SET-PERSONAL-*`

> ⚠️ 원본 시트의 설정 영역은 **메뉴 트리만** 있고 상세 동작은 R367~R373의 일반 문장뿐이다. 이 spec은 가장 빈틈이 많다.

## 메뉴 구조 (IA 기준)

```
설정
├─ 내 계정
│  └─ 로그인 정보: 닉네임(수정) / 연결된 계정 / 로그아웃 / 계정 삭제
├─ 알림 설정: 일정 종료 알림 / 컨디션 기록 알림 / 추천 일정 알림
├─ 추천 개인화 설정
│  ├─ 일정 추천 기준 > 추천 조건: 최소 빈 시간 / 제외할 시간대
│  ├─ 컨디션 회복 방법: 짧은 낮잠 / 음악 감상 / 산책 / 스트레칭 / 간식 / 직접 입력
│  ├─ 수면시간별 컨디션: 위험 / 부족 / 적정 / 과다 / 목표 수면 시간 / 편집
│  ├─ 하루 활동 패턴: 집중 잘 되는 시간 / 졸린 시간 / 수면 시간 / 편집
│  └─ 기본 이동 수단: 도보 / 자전거 / 대중 교통 / 자동차
└─ 이용 안내: 앱 버전 / 서비스 이용약관 / 개인정보 처리방침
```

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 알림 켜고 끄기 (Priority: P1)

**Acceptance Scenarios**:

1. **Given** `SET-MAIN`, **When** 알림 항목 토글을 누르면, **Then** 그 항목만 켜지거나 꺼지고 저장된다. 저장 실패 시 이전 상태로 돌아가고 안내한다.
2. **Given** OS 알림 권한 거부 상태, **When** 토글을 켜려 하면, **Then** [NEEDS CLARIFICATION: Q-036 OS 설정으로 안내? 켜지지 않음?]

---

### User Story 2 - 추천 개인화 값 바꾸기 (Priority: P2)

**Acceptance Scenarios**:

1. **Given** 온보딩에서 입력한 값, **When** 추천 개인화 설정을 열면, **Then** 같은 값이 보인다.
2. **Given** 수면시간별 컨디션의 편집, **When** 구간을 바꾸고 저장하면, **Then** 온보딩과 같은 규칙(30분 단위, 구간 최소 30분)이 적용된다.

## Requirements *(mandatory)*

### Functional Requirements

**설정 메인**

- **FR-SET-001**: GNB 설정 탭 진입 시 계정 정보, 알림 설정, 추천 개인화 설정, 이용 안내 메뉴를 표시한다. GNB 표시. (R367, R372, POL-001)
- **FR-SET-002**: 상단에 로그인한 사용자의 계정 정보를 표시한다. 조회 실패 시 기본 화면 유지. (R368) 표시 항목(닉네임? 소셜 아이콘?): [NEEDS CLARIFICATION: Q-037]
- **FR-SET-003**: 계정 정보 영역을 누르면 계정 정보 수정 화면으로 이동한다. (R369)
- **FR-SET-004**: 메뉴 항목을 누르면 해당 하위 화면으로 이동한다. 불러오지 못하면 현재 화면 유지. (R373)

**내 계정** [NEEDS CLARIFICATION: Q-037, Q-039]

- **FR-SET-010**: 닉네임 수정: 기본값 출처(소셜 프로필?), 글자 수, 허용 문자, 중복 허용.
- **FR-SET-011**: 연결된 계정: 표시만 하는가, 추가 연결·해제가 되는가.
- **FR-SET-012**: 로그아웃: 확인 모달 여부, 이후 `AUTH-LOGIN`으로 이동(제안). 기기에 남는 데이터(최근 검색어 등) 처리.
- **FR-SET-013**: 계정 삭제: 확인 절차, 삭제되는 데이터 범위, 유예 기간, Apple 토큰 철회(001 FR-AUTH-010).

**알림 설정**

- **FR-SET-020**: 일정 종료 / 컨디션 기록 / 추천 일정 알림 토글과 현재 상태를 표시한다. (R339~R341, R370)
- **FR-SET-021**: 각 토글은 개별로 저장한다. 실패 시 기존 값 유지 + 오류 안내. (R371)
- **FR-SET-022**: 초기값은 알림 허용 안내 결과를 따른다 (허용+OS 허용 → 모두 켜짐, 그 외 → 모두 꺼짐). (003 FR-HOME-023, FR-HOME-024)
- **FR-SET-023**: OS 권한이 거부된 상태의 토글 동작: [NEEDS CLARIFICATION: Q-036]

**추천 개인화 설정** (값 규칙은 002와 동일해야 함)

- **FR-SET-030**: 최소 빈 시간, 제외할 시간대를 설정한다. [NEEDS CLARIFICATION: Q-020 의미, 단위, 기본값]
- **FR-SET-031**: 컨디션 회복 방법: 온보딩 FR-ONB-010~013과 같은 규칙. [NEEDS CLARIFICATION: Q-013 항목명 불일치 — IA "산책, 간식" ↔ 온보딩 "가벼운 산책, 음식/간식"]
- **FR-SET-032**: 수면시간별 컨디션: 온보딩 FR-ONB-020~023과 같은 규칙. "편집" 진입 방식(같은 화면 재사용 제안).
- **FR-SET-033**: 하루 활동 패턴: 온보딩 FR-ONB-030~033과 같은 규칙.
- **FR-SET-034**: 기본 이동 수단: 온보딩 FR-ONB-040과 같은 규칙.
- **FR-SET-035**: 값을 바꾸면 이미 계산된 추천·점수에 언제부터 반영되는가 (즉시? 다음 날?): [NEEDS CLARIFICATION: Q-089]

**이용 안내**

- **FR-SET-040**: 앱 버전을 표시한다. (R364)
- **FR-SET-041**: 서비스 이용약관, 개인정보 처리방침 전문을 볼 수 있다. (R365, R366)
  - 로그인 화면의 "개인정보 수집 및 이용약관"(001)과 "개인정보 처리방침"은 다른 문서다. 둘 다 필요하다.
