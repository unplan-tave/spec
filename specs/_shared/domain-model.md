# 도메인 모델 (개념)

> 테이블 설계가 아니라 **FE·BE·디자인이 같은 개념을 공유하기 위한** 엔티티 정의다. 물리 스키마는 BE 레포 `data-model.md`에서 다룬다.
> 각 속성의 제약은 원본 행 번호와 함께 적는다. `⚠️`는 미확정.

## User (계정)

| 속성 | 필수 | 규칙 |
|---|---|---|
| 소셜 계정 연결 | ✅ | Apple / Google / Kakao 중 1개 이상 (R5~R8). 여러 개 연결 가능 여부 ⚠️ (Q-039) |
| 닉네임 | ⚠️ | 규칙 미정의 (Q-037) |
| 온보딩 완료 여부 | ✅ | 온보딩 마지막 단계 완료/건너뛰기 시 `true` (R58) |
| 알림 안내 선택 완료 여부 | ✅ | 알림 허용 안내 모달에서 선택 시 `true` (R68) |

## UserPreference (추천 개인화 설정)

온보딩에서 입력하고 설정 탭에서 수정한다.

| 속성 | 필수 | 규칙 |
|---|---|---|
| 컨디션 회복 방법 | ✅ 1개 이상 | 기본 항목 5개 + 직접 입력 최대 1개 (R27~R31). 순서 ⚠️ (Q-013) |
| 수면 구간 경계 | ✅ | 위험/부족/적정/과다. 기본 0~3 / 3~6 / 6~9 / 9초과(h). 30분 단위, 구간 최소 30분 (R34~R35) |
| 목표 수면 시간 | ✅ | 기본 7시간 30분 (R34). 단위·범위 ⚠️ (Q-056) |
| 집중 잘되는 시간대 | - | 0~24시, 1시간 단위, 여러 구간 (R42) |
| 졸린 시간대 | - | 0~24시, 1시간 단위, 여러 구간 (R43) |
| 수면 시간대 | ✅ 1시간 이상 | 0~24시, 1시간 단위, 여러 구간 (R44~R45) |
| 선호 이동 방식 | - | 0개 이상 (건너뛰기 가능) (R48~R50) |
| 최소 빈 시간 | ⚠️ | 설정 IA에만 존재 (Q-020) |
| 제외할 시간대 | ⚠️ | 설정 IA에만 존재 (Q-020) |
| 알림 설정 | ✅ | 일정 종료 / 컨디션 기록 / 추천 일정 알림 각각 on/off (R67, R71, R72) |

## Card (일정 카드)

공통 속성:

| 속성 | 필수 | 규칙 |
|---|---|---|
| 종류 | ✅ | `pin` / `queue`. 신규 기본값 `pin` (R180) |
| 제목 | ✅ | 1자 이상 (R184) |
| 컨디션 태그 | ✅ | 6개 중 정확히 1개. 신규 기본값 `일상 작업`, 제목 입력 시 자동 분류 (R185, R191) |
| 개인 태그 | - | 0개 이상 (R201) |
| 위치 | - | 검색어 문자열 (R230). 좌표/장소 ID 여부 ⚠️ (Q-057) |
| 상세 위치 | - | 위치가 있을 때만 입력 가능 (R231) |
| 메모 | - | 0~2,000자 (R232) |
| 진행도 | ✅ | `not_started` / `in_progress` / `done`. 기본 `not_started` (R151) |

핀 카드 전용:

| 속성 | 필수 | 규칙 |
|---|---|---|
| 시작일·종료일 | ✅ | 단일 날짜 또는 기간 (R206~R207) |
| 시작 시각·종료 시각 | ✅ ⚠️ | 00:00~23:59 (R209~R210). "이대로 저장하기"로 시각 없이 저장 가능한지 모순 (Q-006) |
| 반복 | ⚠️ | IA에만 존재 (Q-030) |
| 알림 | ⚠️ | IA에만 존재 (Q-030) |

큐 카드 전용:

| 속성 | 필수 | 규칙 |
|---|---|---|
| 마감일 | ✅ | 날짜 1개 (R243) |
| 소요 시간 | ✅ | 분 단위 누적 값 또는 `미정` (R247~R248). 0시간 0분의 유효성 ⚠️ (Q-047) |

**불변 조건**
- 핀 카드끼리 시간이 겹치면 안 된다. 끝 시각과 다음 시작 시각이 같아도 겹침으로 본다 (R218). ⚠️ (Q-022)
- 큐 카드 → 핀 카드 전환 시 제목, 컨디션 태그, 개인 태그, 위치, 메모, 진행도는 유지한다 (R167). 카드 ID 유지 여부 ⚠️ (Q-058)

## PersonalTag (개인 태그)

| 속성 | 규칙 |
|---|---|
| 이름 | 1~25자, 계정 내 중복 불가 (제안) (R199) |
| 정렬 | 가나다순 (R200) |

## DailyMemo (날짜별 메모)

| 속성 | 규칙 |
|---|---|
| 날짜 | 1개 날짜에 여러 개 (R91). 최대 개수 ⚠️ (Q-034) |
| 내용 | 1~20자 (R96) |
| 순서 | 표시 순서 기준 ⚠️ (Q-034) |

## ConditionRecord (컨디션 기록)

| 속성 | 규칙 |
|---|---|
| 일시 | 날짜 + 시각. 신규 기본값 현재 일시 (R302) |
| Body 값, Mind 값 | 사분면 그래프의 위치 1개 (R303). 값 범위·단위 ⚠️ (Q-049) |

## SleepRecord (수면 기록)

| 속성 | 규칙 |
|---|---|
| 시작 일시, 종료 일시 | 종료는 시작 이후 (R329) |
| 유형 | `sleep` / `nap` / `all_nighter` ⚠️ (Q-015) |
| 총 수면 시간 | 자동 계산값, 사용자가 직접 수정 가능. 둘을 별도로 관리 (R330) ⚠️ (Q-016) |
| 귀속 날짜 | 수면 **시작 날짜** 기준 (R333) |

## Notification (알림)

| 속성 | 규칙 |
|---|---|
| 종류 | 일정 종료 / 컨디션 기록 / 추천 일정 (R64). 생성 조건 ⚠️ (Q-035) |
| 탭 분류 | 전체 / 완료(일정 진행도 관련) (R114~R115) |

## RecentSearch (최근 검색어)

카드 검색용, 위치 검색용 두 종류. 저장 위치(기기/계정)와 최대 개수 ⚠️ (Q-032)

## RecommendationExclusion (추천 제외)

| 속성 | 규칙 |
|---|---|
| 큐 카드, 날짜 | "오늘 추가하기 좋은 일정"에서 삭제한 큐 카드는 그날 다시 추천하지 않음 (R174). 하루의 경계 ⚠️ (Q-045) |
