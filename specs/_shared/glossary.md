# 용어집 (Glossary)

> 모든 문서, 디자인, 코드에서 아래 표기만 사용한다. 코드 식별자는 FE/BE 공통으로 `코드값` 열을 따른다.
> `⚠️ 미확정` 표시는 `open-questions.md`의 해당 질문이 결정되면 갱신한다.

## 카드

| 용어 | 코드값 | 정의 |
|---|---|---|
| 일정 카드 | `card` | 사용자가 등록한 일정 단위. 핀 카드와 큐 카드를 통칭한다. |
| 핀 카드 | `pin` | 날짜와 시작·종료 시각이 정해진 일정. ("정해진 일정은 핀 카드로") |
| 큐 카드 | `queue` | 시각이 정해지지 않은 할 일. 마감일과 소요 시간을 가진다. ("할 일은 큐 카드로 담고") |
| 핀 카드 전환 | `convert` | 큐 카드에 시작·종료 시각을 부여해 핀 카드로 바꾸는 것. |
| 추천 큐 카드 | - | 추천 로직이 특정 빈 시간에 넣기 좋다고 제안한 큐 카드. |

## 진행도 ⚠️ 미확정 (Q-004)

원본에 두 가지 표기가 혼재한다. 결정 전까지 코드값만 고정한다.

| 코드값 | 후보 표기 A (필터, 초기 명세) | 후보 표기 B (카드 상세) |
|---|---|---|
| `not_started` | 미완료 | 시작 전 |
| `in_progress` | 진행중 | 진행 중 |
| `done` | 완료 | 완료 |

- 완료 카드: 진행도가 `done`인 카드. 목록에서 제목에 취소선을 표시한다.

## 컨디션 태그

카드 1개에 반드시 1개만 지정한다. 기본값은 `일상 작업`.

| 표기 | 코드값 |
|---|---|
| 긴급 처리 | `urgent` |
| 핵심 작업 | `core` |
| 두뇌 활동 | `brain` |
| 일상 작업 | `routine` |
| 단순 노동 | `simple` |
| 기력 회복 | `recovery` |

> 표시 순서: 원본에 두 가지 순서가 있음 (R134: 핵심→두뇌→일상→기력→단순→긴급 / R191: 긴급→핵심→두뇌→일상→단순→기력). 디자인 확정 순서를 따른다. (Q-051)

## 개인 태그

- 사용자가 직접 만든 태그. 카드에 0개 이상 지정. 이름 1~25자, 계정당 최대 100개.

## 컨디션

| 용어 | 코드값 | 정의 |
|---|---|---|
| 컨디션 기록 | `condition_record` | 특정 일시에 사용자가 사분면 그래프에 찍은 Body/Mind 값 1건. |
| Body Score / Mind Score / Sleep Score | `body`, `mind`, `sleep` | 컨디션 세부 점수. 산정식은 `specs/007-recommendation` 참조. |
| 컨디션 총점 | `total_score` | 세부 점수로 계산한 날짜(또는 기간)별 점수. |
| 컨디션 멘트 | - | 컨디션 상태에 따른 "상태 진단 + 행동 권유" 문구. |
| 에너지 측정 | - | 컨디션 기록을 추가/수정하는 화면 (`COND-ENERGY`). |
| 컨디션 회복 방법 | `recovery_method` | 기력 회복이 필요할 때 추천에 쓰는 사용자 선호 활동. |

## 수면

| 용어 | 코드값 | 정의 |
|---|---|---|
| 수면 기록 | `sleep_record` | 시작 일시~종료 일시와 총 수면 시간을 가진 1건. |
| 수면 유형 | `sleep_type` | `sleep`(수면) / `nap`(낮잠) / `all_nighter`(밤샘). ⚠️ 조합 규칙 미확정 (Q-015) |
| 수면 시간별 컨디션 구간 | `sleep_zone` | `danger`(위험) / `short`(부족) / `optimal`(적정) / `excess`(과다) |
| 목표 수면 시간 | `target_sleep` | 기본 7시간 30분. |
| 하루 활동 패턴 | `daily_pattern` | 집중 잘되는 시간, 졸린 시간, 수면 시간대 (0~24시, 1시간 단위). |

## 화면/UI

| 용어 | 정의 |
|---|---|
| GNB | 하단 글로벌 내비게이션. 홈 / 카드리스트 / 일정 추가 / 컨디션 / 설정. 노출 규칙은 POL-001. |

| 토스트 바 | 일시 안내 바. 공통 규칙은 POL-002. |
