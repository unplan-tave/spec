# 결정이 필요한 질문 (Open Questions)

> 원본 시트를 이관하면서 발견한 **모순**(같은 내용을 다르게 정의)과 **빈틈**(정의 없음).
> 각 spec의 `[NEEDS CLARIFICATION: Q-###]`은 여기 ID를 가리킨다.
>
> **처리 방법**: 질문 1개 = GitHub Issue 1개 (`clarification` 라벨). 결정되면
> ① 이 표의 `결정` 열을 채우고 ② 관련 spec의 표시를 실제 요구사항으로 바꾸고 ③ Issue를 닫는다.
>
> 유형: 🔴 모순 / 🟡 빈틈 / ⚖️ 법무·정책 검토
> 담당: 기획 / 디자인 / BE / FE (결정 책임자)
